# Microservices-ACMEMobility
Project for the Distributed Systems course at University of Bologna 2025/2026. A simulation of a **Distributed Cyber-Physical System (CPS)** managing a "Smart Roundabout".  

## Requirements

- docker


## Commands

Start all services:
```bash
./src/start.sh
```

Stop all services:
```bash
./src/down.sh
```
